# 📚 BookVerse

A modern Full Stack Book Store Management System built using **React.js**, **Spring Boot**, and **MySQL**. BookVerse provides an intuitive online bookstore experience where users can browse books, search titles, filter by categories, manage shopping carts, and explore featured collections through a clean and responsive interface.

---

## 🚀 Features

### 👤 User Features
- Secure User Authentication
- Browse books by category
- Search books by title, author, publisher, or ISBN
- Advanced filtering
- Wishlist management
- Shopping cart
- Responsive design
- Light/Dark mode support
- View book details
- Rating display
- Latest releases sorting

### 🛠️ Admin Features
- Manage books
- Manage categories
- Inventory management
- User management
- Order management
- Dashboard for administration

# 💻 Installation

## Clone Repository

```bash
git clone https://github.com/Thanvika-gali/BookVerse.git
```

---

## Backend

```bash
cd backend
```

Configure **application.properties** with your MySQL credentials.

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/bookverse
spring.datasource.username=root
spring.datasource.password=yourpassword
```

Run

```bash
mvn spring-boot:run
```

Backend runs on

```
http://localhost:8080
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on

```
http://localhost:5173
```
